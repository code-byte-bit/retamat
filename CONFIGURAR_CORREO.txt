RETAMAT — RECUPERACIÓN DE CONTRASEÑA

RETAMAT utiliza códigos de respaldo (sin necesidad de configurar servidores de correo ni pagar servicios externos):

1. ¿Cómo funciona?
   - Al crear una cuenta (desde el botón "Crear cuenta"), el sistema genera automáticamente un Código de Recuperación único de 8 caracteres (por ejemplo: A7K2-9M4P).
   - Se muestra en una ventana destacada para que el usuario lo anote o copie.
   - Si el usuario olvida su contraseña:
     * Hace clic en "¿Olvidaste tu contraseña?"
     * Escribe su correo, su código de recuperación y la nueva contraseña.
     * La contraseña se actualiza de inmediato y el sistema genera automáticamente un NUEVO código de respaldo para el futuro.

2. Restablecimiento desde el Administrador:
   - Si el usuario llega a perder su código de respaldo, cualquier Administrador puede cambiarle la contraseña directamente desde el panel de "Usuarios".

3. Ventajas:
   - Funciona al 100% en Render, TiDB Cloud, localhost o cualquier servidor sin requerir cuentas de correo, contraseñas de aplicación ni puertos SMTP.
